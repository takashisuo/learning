# SQL Server サンプルクエリ集

このフォルダは デザインパターン に関するサンプルPythonコードを記載する場所です。

## 目的

- デザインパターンの各種構文・機能をサンプルとして蓄積する
- 実務でよく使うパターンや、学習・参照用のパターンを整理する

## 対象範囲

- Python
- 実務で活用機会が多いパターン
- データ分析・AI開発で活躍するパターン

## 規約

- ファイル名は内容が分かる英語のスネークケースで命名する（例: `window_functions.sql`）
- 各クエリにはコメントで目的・用途を簡潔に記載する
- 動作確認済みの Python, ライブラリバージョンがあればコメントに明記する
