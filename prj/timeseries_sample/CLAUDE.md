# 保険販売量予測モデル 検討サマリ（Claude Code引き継ぎ用）

## 背景・要件
- 保険の販売サイクル：t月21日〜t+1月20日で概算計上（月次サイクル）
- 予測対象：マーケット統括部（5部）、支社（約100支社）単位
- 予測タイミング：
  - ① t月21日時点でt+1月20日までの着地を予測
  - ② t+1月1日時点で同じ着地を再予測（ローリング再予測）
- 併せてクォーター累計・年間累計も予測したい
- データ制約：5月分・6月分の2ヶ月分の実績のみ（支社以上の粒度）。時系列学習データとしては極めて少ない
- 方針：将来的にAI（時系列モデル）へ移行する前提で、まずは簡易な統計/ルールベースモデルで運用を開始する

## 重要な業務仕様（キーポイント）
**t月21日の計上値は「月初でゼロからのスタート」ではない。**
保険の計上テクニックとして、t月15日前後〜20日頃までに実売した分を「t月21日」にまとめて計上することができる。
→ t月21日の値は、通常の1日分の実績ではなく、**先行計上分を含んだスパイク（塊）**として扱う必要がある。

## 採用する予測ロジック

### 基本方針：累積比率カーブによる割り戻し方式
単純な「残日数で線形按分」ではなく、**月内の実際の売れ方の形（スパイク＋通常積み上げ）を反映した累積比率カーブ**を使い、実績を月末着地に割り戻す。

```
予測値 = 現時点までの累積実績 ÷ その経過日数における「対月末累積比率」
```

### 月内カーブの2区間構造
| 区間 | 内容 |
|---|---|
| ①スパイク区間（21日時点） | 先行計上分。比率 = day21実績 ÷ 当月末実績 |
| ②通常積み上げ区間（22日〜翌月20日） | スパイク以降の通常ペースでの積み上げ |

- 5月・6月それぞれで①のスパイク比率を算出し、安定しているか確認する（2点しかないため暫定値）
- ②の区間は経過日数ごとの累積比率カーブとして作成

### ローリング再予測
- t月21日時点：day21実績（スパイク込み） ÷ スパイク比率 → 月末着地予測
- t+1月1日時点：21日〜1日までの累積実績 ÷ 対応する累積比率 → 月末着地予測を再計算（前の予測を上書き）
- 実績が積み上がるほど、古い予測ではなくその都度の実績ベースで引き直す

### 階層（統括部⇄支社）の扱い：シュリンク方式
- 支社単位（100支社）は2ヶ月分のデータではサンプルが薄すぎるため、まずは**統括部単位（5部）で共通の累積比率カーブ・スパイク比率**を作り、支社にはそれを適用する
- 支社合計と統括部予測に乖離があれば、統括部予測に合わせてトップダウンで按分・整合させる
- 将来データが溜まったら、支社別の実績を部分的に反映（Empirical Bayes的な加重平均）していく

### 曜日による増減率の調整（将来拡張）
- 曜日効果は現状データ量（2ヶ月、支社あたり曜日サンプル約8〜9回）では支社別には不安定
- 現段階：全社 or 統括部（5部）単位で曜日係数を算出
- 将来（データ半年〜1年）：支社の実績量に応じた加重平均でシュリンクしながら支社別へ移行
  ```
  支社の曜日係数 = w × (支社自身の曜日パターン) + (1-w) × (統括部の曜日パターン)
  w は支社のデータ量が増えるほど大きくする
  ```

## クォーター・年間累計予測
- 月次予測の単純合算でよい（複雑なモデル不要）
- 先の月ほど不確実性が高いため、予測値に加えて上振れ/下振れレンジ（例：前月比±10%等）も併記する

## リスク・注意点
- スパイク比率・曜日係数は現状2ヶ月分のみのため暫定値。7月以降のデータで随時更新する前提
- 「計上日」と「実売日」がズレている場合、月をまたいだ訂正計上が発生し月末実績が事後的に動くリスクあり。速報値と確定値を分けて管理するのが望ましい
- スパイクの出方（先行計上の運用度合い）が支社ごとに異なる可能性があるため、極端な支社がないか初期チェックが必要

## 今後のフェーズ
| フェーズ | データ量目安 | 手法 |
|---|---|---|
| フェーズ0（現在） | 2ヶ月 | 本資料のルールベース/簡易統計モデル |
| フェーズ1 | 6〜12ヶ月 | 指数平滑法・Holt-Winters等 |
| フェーズ2 | 1〜2年以上 | 回帰/MLモデル（LightGBM等、稼働日数・キャンペーン等を特徴量化） |

## Claude Codeでやりたいこと（次のステップ）
1. 実際の5月・6月の支社別・統括部別販売データ（CSV等）を読み込む
2. day21実績とその月の月末実績から、統括部ごとの**スパイク比率**を算出
3. 22日〜20日の経過日数ごとの**累積比率カーブ**を作成（統括部単位）
4. 上記カーブを使って、7月分の予測を①21日時点②1日時点のシナリオでシミュレーションし、実績と比較
5. カーブ・スパイク比率・予測結果を可視化（折れ線グラフ、統括部別の比較など）
6. （データが揃えば）曜日係数の試算も追加

※サンプルデータファイル（CSV等）を作業フォルダに置いて作業をしてください。
列構成（日付、統括部、支社、販売数など）が分かる形であれば、そのままスクリプト化できます。
