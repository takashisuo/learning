# quiz-app

一般常識クイズアプリ。HTML/CSS/JavaScript のみで構築するフロントエンド完結型のアプリケーション。

## プロジェクト概要

- **アプリ名**: quiz-app
- **種別**: 一般常識クイズアプリ
- **技術スタック**: HTML / CSS / JavaScript（バニラ）
- **動作環境**: ブラウザのみ（サーバー不要）

## ディレクトリ構成（想定）

```
quiz-app/
├── index.html        # エントリーポイント
├── css/
│   └── style.css     # スタイル定義
├── js/
│   └── main.js       # アプリロジック
└── data/
    └── questions.js  # クイズ問題データ
```

## 開発方針

- 外部ライブラリ・フレームワークは使用しない（バニラ JS のみ）
- `index.html` をブラウザで直接開いて動作すること
- モバイル・デスクトップ両対応のレスポンシブデザイン
- アクセシビリティを意識した実装（適切な ARIA 属性、キーボード操作対応）

## 機能要件

- クイズ問題の表示（テキスト形式の 4 択）
- 回答の選択と正誤判定
- スコアの集計と結果表示
- 問題のランダム出題

## コーディング規約

- インデント: スペース 2 つ
- セミコロン: あり
- 文字列: シングルクォート
- コメント: 日本語可
- `const` / `let` を使用し、`var` は使用しない
- DOM 操作は `querySelector` / `querySelectorAll` を使用

## 動作確認方法

`index.html` をブラウザで直接開く（Live Server 等の使用も可）。

```bash
# VS Code の Live Server 拡張を使う場合
# index.html を右クリック → "Open with Live Server"
```

## 注意事項

- 返答は必ず日本語で行うこと
