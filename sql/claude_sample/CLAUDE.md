# SQL Server サンプルクエリ集

このフォルダは SQL Server に関するサンプルクエリを記載する場所です。

## 目的

- SQL Server の各種構文・機能をサンプルクエリとして蓄積する
- 実務でよく使うパターンや、学習・参照用のクエリを整理する

## 対象範囲

- DDL（テーブル作成・変更・削除など）
- DML（SELECT / INSERT / UPDATE / DELETE）
- ウィンドウ関数・集計・サブクエリ
- ストアドプロシージャ・関数・トリガー
- インデックス・パフォーマンスチューニング
- SQL Server 固有の構文（T-SQL）

## 規約

- ファイル名は内容が分かる英語のスネークケースで命名する（例: `window_functions.sql`）
- 各クエリにはコメントで目的・用途を簡潔に記載する
- 動作確認済みの SQL Server バージョンがあればコメントに明記する
